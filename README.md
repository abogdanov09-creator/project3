## 🎯 Описание проекта

Скрапер собирает данные о книгах с тестового сайта **books.toscrape.com**.

### Что собирается:

| Данные | Описание | Пример |
|--------|----------|--------|
| Название | Полное название книги | "Sapiens: A Brief History of Humankind" |
| Цена | Цена в GBP (фунтах) | 54.23 |
| Рейтинг | Оценка от 1 до 5 звёзд | 5 |
| Наличие | В наличии / Нет в наличии | in_stock |
| Категория | Категория товара | books |
| Дата сбора | Время добавления записи | 2026-06-30 15:30:00 |

### Что делает проект:

1. **Собирает данные** с сайта books.toscrape.com
2. **Сохраняет** их в CSV-файл
3. **Анализирует** данные (средняя цена, топ книг, рейтинги)
4. **Строит график** распределения цен
5. **Может работать непрерывно** с заданным интервалом

## 📋 Требования

### Системные требования:

- **Python:** версия 3.8 или выше
- **Операционная система:** Windows, macOS, Linux
- **Интернет:** доступ к сайту books.toscrape.com

### Зависимости (библиотеки):

| Библиотека | Версия | Для чего |
|------------|--------|----------|
| requests | последняя | HTTP-запросы к сайту |
| beautifulsoup4 | последняя | Парсинг HTML |
| pandas | последняя | Работа с данными |
| matplotlib | последняя | Построение графиков |
| schedule | последняя | Планирование запусков |
